# Flying Demon - A Spooky Flappy Bird Game

This is a haunted-themed Flappy Bird game where you control a ghostly entity and navigate through eerie obstacles in a graveyard setting.

## How to Play
- Click **Start** to begin your ghostly flight.
- Tap or click to make the ghost ascend.
- Avoid obstacles to increase your score.
- If you collide with an obstacle, the game ends, but you can try again!

## Features
- **Spooky Atmosphere:** A dark and eerie background enhances the horror feel.
- **Smooth Controls:** Easy and responsive clicking mechanics.
- **Dynamic Obstacles:** Pipes appear at different heights to challenge your skills.
- **Score Tracking:** Keep track of your best runs.

## Technologies Used
- **Java** for core game logic.
- **Swing** for GUI implementation.
- **Custom Graphics** for background, character, and obstacles.

## Setup and Run
1. Clone the repository.
2. Compile and run `Main.java` using your preferred Java IDE or terminal.
3. Enjoy the ghostly adventure!
